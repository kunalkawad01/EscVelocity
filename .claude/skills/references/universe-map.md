## F&O Universe

The F&O universe is a **cross-cutting filter** — not a separate sector structure.
Apply it to whichever base universe is selected (N50/N200/N500) and show only stocks
where `isFnO: true`.

Current F&O-eligible stocks are marked ✓ in the tables above.

To get the definitive live list, hit:

```
GET https://api.kite.trade/instruments?exchange=NFO
```

Filter for `instrument_type == "FUT"` and extract unique underlying symbols.

## Notes for Implementation

1. Store this map as a JS object keyed by universe name
2. On universe switch, recompute `activeSectors` and `activeStocks`
3. F&O filter: if `universe === 'fno'`, keep sectors but filter stocks to `isFnO === true`; hide sectors with 0 remaining stocks
4. Sector color is fixed regardless of universe
5. Momentum score and breadth are recomputed from whatever stocks remain after filtering
