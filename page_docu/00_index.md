## How to use this folder

When adding or redesigning a page:
1. Read the relevant page doc to understand existing business logic before touching code.
2. Check the **Suggestions** section — it contains validated improvement ideas.
3. Cross-reference `indicators_page.md` for UI/design system conventions.
4. After shipping changes, update the page doc — stale docs are worse than no docs.
