# MarketDNA

Quantitative research platform for Indian equities, futures, and options.
Built for portfolio construction research, options intelligence, and macro analysis on NSE data.

**Stack:** FastAPI · DuckDB · Polars · React · MUI · Highcharts

---

## Prerequisites

| Tool | Version |
|------|---------|
| Python | 3.12+ |
| Node.js | 18+ |
| Kite Connect account | Required for data ingestion |

---

## Setup

### 1. Clone

```bash
git clone https://github.com/kunalkawad01/EscVelocity.git
cd EscVelocity
```

### 2. Backend

```powershell
cd marketdna-backend
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
```

Create `.env` in `marketdna-backend/`:

```env
# Optional — only needed for AI Research Assistant (Ollama)
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=llama3
```

### 3. Data pipeline

```powershell
cd marketdna-data
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
```

Create `.env` in `marketdna-data/`:

```env
KITE_API_KEY=your_api_key
KITE_API_SECRET=your_api_secret
KITE_ACCESS_TOKEN=your_access_token   # refreshes daily
```

> The access token expires every day. Generate a new one each session via the Kite Connect developer console.

### 4. Ingest data

Run once to download historical OHLCV (takes 10–20 min for NSE 500):

```powershell
cd marketdna-data
.\.venv\Scripts\python -m ingestion.download_nse500
.\.venv\Scripts\python -m warehouse.register_views
.\.venv\Scripts\python -m feature_engine.compute_all
```

After the first run, `download_nse500` is incremental — re-run daily to append new bars only.

### 5. Frontend

```powershell
cd marketdna-web
npm install
```

## Run

From the repo root:

```powershell
.\start-marketdna.ps1
```

Or manually:

```powershell
# Terminal 1 — backend
cd marketdna-backend
.\.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

# Terminal 2 — frontend
cd marketdna-web
npm run dev -- --host 127.0.0.1
```

| URL | Purpose |
|-----|---------|
| http://localhost:5173 | App |
| http://localhost:8000 | API |
| http://localhost:8000/docs | API docs (Swagger) |

> **First startup takes ~30 s** — the backend pre-warms regime scores, breadth, delivery reports, and the indicator scan before accepting connections. Subsequent requests are instant.

## Data lake layout

```
marketdna-data/
  data_lake/
    raw/equities/symbol=XXX/data.parquet   ← OHLCV (gitignored, generated by ingestion)
    features/                               ← computed features (gitignored)
    derived/                                ← scan results & backtests (gitignored)
```

The data lake is **not included in the repo** — run the ingestion pipeline to populate it.
